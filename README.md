# 📊 Customer Churn Prediction Dashboard

An end-to-end Machine Learning project that predicts customer churn using XGBoost and Random Forest, with an interactive Streamlit dashboard.

## 🎯 Features

- ✅ Auto-generated realistic dataset (5,000+ records)
- ✅ Data preprocessing with label encoding + standardization
- ✅ Model comparison: Random Forest vs XGBoost
- ✅ Real-time churn prediction with probability gauge
- ✅ Interactive visualizations (Plotly)
- ✅ Confusion matrix, correlation heatmap
- ✅ Clean, professional dashboard UI

## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **ML:** Scikit-learn, XGBoost
- **Data:** Pandas, NumPy
- **Viz:** Plotly
- **Web App:** Streamlit
- **Model Persistence:** Joblib
